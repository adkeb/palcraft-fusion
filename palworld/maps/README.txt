离线箱子位置图生成器

使用 Python 3.9 或更新版本，无额外依赖。脚本只读取本地 JSON，不能控制游戏，
不会连接服务器、上传数据或加载外部网页。生成的单个 HTML 可直接发给队友，
浏览器离线打开即可查看；不需要复制此目录的其他文件。

命令示例（路径需要替换为实际文件）：

  python3 generate-chest-map.py \
    --base 旧基地 old-plan.json old-after.json \
    --base 新基地 new-plan.json new-after.json \
    --base 第三基地 third-plan.json third-after.json \
    --output 箱子位置图.html

每个 --base 后面依次为：显示名称、最后执行的方案 JSON、整理后的实际读取 JSON。
方案必须是 storage.plan 的完整结果，读取必须是同基地 storage.list 的完整结果，
包括所有空槽和实际物品。支持直接结果及 MCP JSON 信封。

图中格数和物品数量取自 after JSON；位置、已知物品分类取自方案。两者不一致时
会标注差异，不把方案内容冒充实际读取。缺少位置的箱子只出现在下方清单中。

圆点使用游戏地图坐标，北向上，同一基地内保持等比例。编号从北到南排列，
只是本图的索引，不会在游戏里修改或标记箱子。可筛选空位箱／混放箱、点击定位、
展开物品清单。箱子 UUID 仅保留在内嵌数据中，不作主要显示。

本图不自动刷新。移动箱子、取放物品后，需要重新读取并生成。图中不包含地形、
建筑轮廓或朝向，多层建筑可能出现重叠；每箱详情中附有相对高度。
