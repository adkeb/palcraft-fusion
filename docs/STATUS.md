# 开发状态与原验收范围

项目保留原 42 项验收范围，不以某个单独组件编译成功代替完整可玩状态。

当前实证包括正常 Mac 单机角色与身份恢复、原 MC 玩家绑定、真实世界快照、部分网格与碰撞提交、日志分卷、既有 AI 生存建造与仓储部分流程。本轮原生世界确认已经实际完成，MC 导出帧缓冲已创建；真实 HUD 像素与完整游戏流程未完成验收。
