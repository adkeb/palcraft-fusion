# Finalize the same original normal stop after its producers are off

The original supervisor calls journal finish once. A temporary false readiness/port observation can leave its truthful actual-wait and save records in incomplete-stop after the supervisor has exited. The precise failed conjunct in the observed earlier stop is unknown; TIME_WAIT is only a possibility. This delta adds an ordinary off-only finalize-stop entry without another save or stop request.

NormalLifecycle.finish still collects exits from its own real Popen handles. The existing readiness, persistent quiet/hash and normal-stop-receipt issuer is shared with finalize_stop. The new entry reads only the same boot's original session/scope/pending, durable save and postsubmission Level witness, correlated Title/Quit observations, host result and recorded actual actor/worker-child waits. Scope and native world/UID must match. Recorded PIDs must be absent from the OS, including the original supervisor. Original host primary/job must be off and normal exit0; original server/guest stop codes and wrapper child waits remain required. Saved/WAL and event volume must remain stable through the two-second quiet interval and hashing, and the original Level witness must still match at issuance.

The original conservative port bind probe remains unchanged and rejects a real LISTEN. Final readiness is checked again before issuance; no SO_REUSEADDR relaxation is introduced. Future incomplete-stop diagnostics retain named readiness checks and failed conjuncts. This candidate does not add repeated shutdown, an arbitrary observer receipt, fake Popen, adopted PID, manual phase/state/hash edits, new SID/key/permission, or a replacement archive protocol.

Use the revised release's original palcraft.py finalize-stop --root entry, or the frozen source overlay below. The overlay pins existing complete core/runtime modules and imports only the revised CLI/journal source. It never copies modules into an installation.

```sh
python3 run_frozen_cli.py --tool-source ORIGINAL_COMPLETE_PLAYER_TOOLS finalize-stop --root OWNED_ROOT
```

`--dry-run` verifies existing source records and current readiness without creating a receipt; it reports that issuance must still check persistent quiet/hashes. Successful non-dry execution writes only the original same-token normal-stop-receipt through the original issuer. It leaves session phase and state unchanged. Original prepare_cold_boot may then consume that receipt and run the original rotator. Do not boot, rotate, save or stop again to substitute for the missing witness.

The temporary test uses actual self-created Popen waits to produce incomplete-stop through the original NormalLifecycle.finish, with native save/Title/host boundaries explicitly simulated. It checks wrong scope, missing actual wait, an actually alive test supervisor, recovery via the same issuer, unchanged phase/Saved/WAL/event files, and a real ephemeral LISTEN refusal. The external CLI import/help path was checked; finalize-stop has not been executed against the actual owned installation by this source task.
