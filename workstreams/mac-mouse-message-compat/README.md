The official Raw Command keeps SteamAppId and all original Wine options; the same explicit value is also carried through the original CX_ENV route. No other launch, UID/world, signature, Save, model or input snapshot contract changes.

The existing native live/focus/no-menu/not-suspended/window/generation gates still apply. Signed client positions become bounded differences in the original cumulative mouse counters. A first point or discontinuous jump above128 pixels rebases only. A tracked own foreground-client center warp supports continuous FPS turns; only its exact acknowledgement resets the baseline. Ordinary20-pixel motion through center without a pending own warp is still motion. The original controls tick observes the real cursor only while a warp is pending; a100ms deadline rebases actual cursor coordinates if the message acknowledgement never arrives. API success is never considered an acknowledgement. No new timer, manager, activation, hotkey, camera/world pose setter or direct game RPC is introduced.

Once real relative RAW appears, ordinary motion and recentering are disabled for that current eligibility epoch. To prefer no double turn, switching after ordinary motion conservatively suppresses at most the first RAW packet even if it is a distinct movement; this candidate does not promise zero input loss at that transition. Outside the explicit Mac mode, original RAW behavior is retained. GUI pointer handling, lost-focus releases, native750ms freshness, original form choice and all current authority/ACK guards remain unchanged.
